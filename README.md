# FlyRank - Flight Search & Ranking Engine

FlyRank is an intelligent flight search and multi-criteria ranking platform designed to deliver optimal travel itineraries based on price, travel duration, layover convenience, and carbon efficiency.

## Overview
- **Project Name:** FlyRank
- **Status:** Initial Setup & Planning Phase
- **Tech Stack:** Node.js, TypeScript, Express / Fastify, React / Next.js
- **License:** MIT

## Features (Planned)
- Aggregated search across multiple airline flight feeds
- Multi-objective ranking algorithms (Pareto-optimal flight options)
- AI-driven itinerary recommendations and layover satisfaction scoring
- Real-time price tracking and volatility alerts

## Quick Start
```bash
npm install
npm run dev
```
